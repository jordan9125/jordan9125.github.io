# 성경 위키

노션의 **성경 위키**에서 글을 쓰고, 이 사이트(https://jordan9125.github.io)에서 읽습니다.

- 노션 데이터베이스에서 **`공개`** 칸을 체크한 글과, 그 글 아래의 **모든 하위 페이지**가 공개됩니다.
- 체크를 끄면 다음 갱신 때 사이트에서 사라집니다.
- 공개하는 것은 제목, 본문, 이미지, `유형`·`태그`뿐입니다. 댓글이나 다른 데이터베이스는 읽지 않습니다.

## 처음 한 번 설정

1. **노션 데이터베이스에 칸 추가**: `성경 위키`에 체크박스 속성을 추가하고 이름을 정확히 `공개`로 지정합니다. 공개할 글을 체크합니다.
2. **노션 연결 만들기**: https://www.notion.so/profile/integrations → 새 내부 연결. 기능은 **콘텐츠 읽기만** 켜고, 콘텐츠 업데이트·삽입, 댓글, 사용자 정보는 끕니다.
3. **성경 위키에 연결 추가**: `성경 위키` 데이터베이스(또는 그 위 `성경` 페이지) 오른쪽 위 ••• → 연결 → 방금 만든 연결을 선택합니다. 다른 비공개 페이지는 공유하지 마세요.
4. **토큰 등록**: 이 저장소 Settings → Secrets and variables → Actions → New repository secret. 이름 `NOTION_TOKEN`, 값은 연결의 비밀 토큰. 토큰은 코드·이슈·채팅에 적지 마세요.
5. **Pages 켜기**: Settings → Pages → Source를 **GitHub Actions**로 선택합니다.
6. Actions 탭 → *Sync Notion and publish site* → **Run workflow**로 첫 실행을 확인합니다.

## 갱신

- 약 15분마다 노션을 확인하고, 바뀐 내용이 있을 때만 `content/`에 저장한 뒤 사이트를 다시 배포합니다. 예약 실행은 몇 분씩 늦어질 수 있습니다.
- 바뀌지 않은 페이지는 다시 읽지 않습니다. 노션 이미지 주소는 시간이 지나면 만료되므로 이미지는 `content/media/`에 저장합니다(파일당 15 MB까지).
- 노션 연결이나 조회가 실패하면 기존 사이트를 그대로 두고 배포를 멈춥니다. Actions 탭에서 오류를 확인할 수 있습니다.
- 공개 저장소에 60일간 활동이 없으면 GitHub가 예약 실행을 멈출 수 있습니다. 그때는 Actions 탭에서 다시 켜 주세요.

## 노션 글이 사이트에서 보이는 방식

| 노션 | 사이트 |
|---|---|
| 주황·노랑 글씨 | 형광펜 |
| 회색 글씨 | 작은 혼잣말 |
| 빨강·파랑 글씨 | 같은 계열 색 글씨 |
| 인용 블록 맨 앞 `(마태복음1:1)` | 성경 구절 카드와 출처 라벨 |
| 콜아웃 | 박스 |
| 제목 1이 `1. 족장의 시대`처럼 번호로 시작 | 번호 배지와 목차 |
| 하위 페이지 목록 | 목록 버튼. 제목이 `○장`으로 끝나면 장 번호 버튼 |
| 데이터베이스 보기, 노션에 직접 올린 동영상·파일 | 표시하지 않음 |

## 바꿀 수 있는 설정

`site.config.json`

- `heroTitle`, `tagline`: 홈 첫 문구
- `typeOrder`: 홈에 나오는 `유형` 순서, `gridTypes`: 카드로 보여줄 유형
- `featured`: 홈 추천 글(노션 페이지 id), 소개 문구, 버튼
- `links`: 홈 아래 바로가기

## 직접 실행

Node.js 22 이상, 추가 패키지 없음.

```sh
node --test          # 테스트
NOTION_TOKEN=... node scripts/sync.mjs   # 노션에서 가져오기
node scripts/build.mjs     # _site/ 에 사이트 만들기
```

무료 사용 범위: 공개 저장소와 GitHub 표준 러너를 사용하며 GitHub Pages·Actions의 사용량 제한이 적용됩니다.
